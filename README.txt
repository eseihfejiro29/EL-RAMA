El-Rama INTERNATIONAL SCHOOL JOS WEBSITE
=========================================

FILES
- index.html       Main website page
- style.css        Responsive design and styling
- content.js      Photos and testimonials: edit this file to add real photos
- script.js        Mobile menu, current year and enquiry form behaviour
- assets/school-logo.jpg  Cropped crest from the supplied letterhead

HOW TO USE
1. Extract the ZIP file.
2. Open index.html in a browser to preview the site.
3. Upload index.html, style.css, script.js and the entire assets folder to your hosting public_html directory using cPanel File Manager.
4. Keep the assets folder beside index.html so the logo path works.

IMPORTANT
- The enquiry form opens the visitor's default email application. It does not store or send messages by itself. For server-side delivery, connect a backend or form service.
- The gallery currently uses designed placeholder panels. Replace them with real school photos when available.
- Confirm the address, phone number, email, classes and admission details before publishing.
- This is a static HTML/CSS/JavaScript website; it does not include a student portal or database.

ADDING REAL PHOTOS
1. Put JPG files in assets/photos/ (resize to about 1600px wide, under 400 KB each).
2. Open content.js and write the file names into hero, about, leader, mosaic and gallery.
3. Replace the sample testimonials with real parent comments (with permission).
4. Upload content.js and the assets folder again.
